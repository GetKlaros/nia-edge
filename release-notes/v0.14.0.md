Release of nia-edge, the client of Nia. It is a pre-release.

**Added**
- **One approval for a whole job.** The host tool `propose_task` sends Nia several host actions at once (install the packages, apply the dry runs' plans, reload the services), with a title. Each step is checked against the catalogue and decided by the role as its call would be; the reviewer approves the held steps together, in one Telegram message or one console page, and sees what `apt-get -s` says each package would pull in. Nothing runs when the task is proposed: the agent then calls each step, which runs once, exactly as listed. The role must list `mcp__host__propose_task`.

**Upgrade from 0.13.0**

`sudo sh update-linux.sh v0.14.0`. Needs a Nia of 25 November 2026 or later (`/v1/tasks`); with an older one, `propose_task` reports that Nia could not be reached and the agent calls each step on its own.
