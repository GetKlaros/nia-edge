Sixth release of nia-edge, the client of Nia. It is a pre-release. Model calls go only through nia-edge, never through Nia; more agents are governed; a role can simulate its agents' shell commands and judge what they did.

**New**
- **One way to the model.** nia-edge calls the provider itself; Nia never carries a prompt. `NIA_RELAY_MODEL_CALLS` is gone: a machine without a provider refuses model calls (`nia-edge provider` sets one).
- **Budgets.** Before each model call nia-edge asks Nia whether the key's budget (€ or $, per day or month) allows it, and after it reports the tokens the provider counted, never content. Past the budget a call is held for approval.
- **A local log.** `nia-edge log` shows what Nia decided (`decisions.jsonl`, 0600): tools, hosts, verdicts and reasons, never a prompt, an argument or an output.
- **More agents governed.** Gemini CLI and OpenCode machine-wide, Pi and Oh My Pi per user: `sudo nia-edge agents onboard gemini-cli|opencode|pi|omp`.
- **Codex's model calls through nia-edge.** `sudo nia-edge agents onboard codex -model`: its requirements select nia-edge as provider, over the user's own.
- **Simulated commands.** A role with `simulate` has each shell command (Claude Code, Codex, Gemini CLI, OpenCode, Pi, Oh My Pi) run first in a sandbox over the user's files, without network; Nia judges what it deleted and changed, whatever its text, and nia-edge writes that effect as it is, once. On Ubuntu 23.10 and later the installer adds an AppArmor profile so nia-edge may make user namespaces.
- **Hermes installer.** A taken-over Hermes keeps no model key; its gateway and Telegram go through nia-edge's proxy; the original is said taken over; `nia-edge agents` runs every hour; running the installer again with the installed binary works.

**Upgrade from 0.5.0**

`sudo sh update-linux.sh v0.6.0`. A machine whose model calls went through Nia needs a provider first: `nia-edge provider`. For the hourly inventory and the AppArmor profile, run `install/linux.sh` (or `hermes-linux.sh`) of v0.6.0 once, with `NIA_EDGE_BINARY` pointing at the new binary. Budgets and simulation need Nia 2026-11-20 or later.

**Not yet**
- Approvals in the agent's own Telegram conversation (a group with Nia's bot).
- Governing on macOS and Windows; Codex's commands simulated inside its own sandbox.

```
sha256sum -c --ignore-missing SHA256SUMS
```
