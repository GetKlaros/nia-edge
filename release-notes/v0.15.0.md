Release of nia-edge, the client of Nia. It is a pre-release.

**Added**
- **One command.** `curl -fsSL https://get.euthyna.io | sudo sh` downloads this release, checks every file against `SHA256SUMS`, finds the agent of the machine (Hermes, OpenClaw, Claude Code, Codex, Gemini CLI, OpenCode) and asks for the connection code shown in the console, read from the terminal without echo. On a machine already connected, the same command updates nia-edge and its services and keeps the key; a new code connects it again, the former key set aside.
- The conformance cases include the roles the console writes for each job.

**Upgrade**

`curl -fsSL https://get.euthyna.io | sudo sh`, from any earlier release (tested from 0.5.0).
