Release of nia-edge, the client of Nia. It is a pre-release.

**Fixed**
- `curl -fsSL https://get.euthyna.io | sh` asks its questions in your terminal, before sudo: which agent to connect, the connection code, or Enter to update. Under `sudo sh`, a script read from a pipe could not read what was typed. Only the parts that need root run with sudo, from the checked release; the code reaches them in a 0600 file, never on a command line.
- A machine whose key file is gone, or whose key Euthyna refuses (revoked), asks for a code and connects again.
- The script runs only once it is downloaded whole.

**Upgrade**

`curl -fsSL https://get.euthyna.io | sh`.
