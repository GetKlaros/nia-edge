Release of nia-edge, the client of Nia. It is a pre-release.

**Fixed**
- `curl -fsSL https://get.euthyna.io | sh`: the connection code is asked as you, then the rest runs with sudo. Under `sudo sh`, a script read from a pipe could not read what was typed (sudo runs it in a terminal of its own). The code passes to the root run in a 0600 file, never on a command line. `| sudo sh` still works when nothing has to be typed.
- With several agents on the machine and no terminal to ask, the first one found is taken (Hermes, then OpenClaw…); `EUTHYNA_AGENT` and `EUTHYNA_FROM` choose another.

**Upgrade**

`curl -fsSL https://get.euthyna.io | sh`.
