Release of nia-edge, the client of Nia. It is a pre-release.

**Added**
- **The agent reads a service's log and the disk usage.** Two read-only host actions: `service_logs` reads the last 200 lines of the journal of a service of the role's catalogue, `disk_usage` the machine's file systems (`df`). Like every host action they run through nia-hostd with fixed programs, only against a release of the model path, and are journaled.
- **Secrets are redacted from every host action's output** before the agent sees it.

**Changed**
- **A payment waits for a person once the session is tainted**, whatever the role allows: what the agent just read may be what asks it to pay. A role in observe mode enforces its payments instead of releasing them. Conformance with the server's engine as of 24 November 2026.

**Upgrade from 0.10.2**

`sudo sh update-linux.sh v0.11.0`, then `sudo -iu hermes hermes gateway restart`. A Nia of 24 November 2026 or later is required; it already holds an older nia-edge's payments in a tainted session.
