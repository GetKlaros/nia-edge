Tenth release of nia-edge, the client of Nia. It is a pre-release. Paying is now one sentence for the agent: send 10 USDC to 0x… for invoice 42.

**Changed**
- **`pay` takes who, how much and why.** Its arguments are `to` (an 0x address), `amount` (USDC, as a decimal) and `reference`. nia-edge asks Nia for the rest (`POST /edge/v1/payment-plan`): the organization's vault that lets the agent pay, its chain, its token and the fees. Nia plans the payment again before signing its visa, so a plan changed on the way gets none. The agent no longer chooses a chain: an agent had picked Base mainnet for a vault on Base Sepolia.

**Upgrade from 0.9.0**

`sudo sh update-linux.sh v0.10.0`, then restart Hermes' gateway (`sudo -iu hermes hermes gateway restart`) so that it reads the tool's new arguments. A Nia of 23 November 2026 or later is required.
