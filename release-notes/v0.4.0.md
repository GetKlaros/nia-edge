Fourth release of nia-edge, the client of Nia. It is a pre-release. It governs the coding agents that run their own tools, Claude Code and Codex, where they already run, and reports the agents of each machine to Nia.

**New**
- **Govern Claude Code and Codex.** `sudo nia-edge agents onboard claude-code` (or `codex`) puts nia-edge's hooks in the machine's managed configuration, which a user cannot turn off: Claude Code's managed settings (HTTP hooks that block when nia-edge is out of reach), Codex's requirements (command hooks, `[features] hooks` pinned on). Before a tool runs, nia-edge decides it as the model path does: with the signed policy, Nia receives the call's hash, never its arguments. A hold is a refusal; a secret in a tool's output is redacted before the model sees it. `-dry-run` shows the change, `status` reports it, `restore` puts the file back byte for byte.
- **`nia-edge hook codex`.** Codex lets a call through when its hook fails: nia-edge's hook answers "deny" whatever fails, within the hook's timeout.
- **A governed machine.** `install/linux.sh --governed` installs and enrolls nia-edge without a user to close, for the agents that keep running where they are.
- **The agents of each machine in the console.** `sudo nia-edge agents` leaves its report on the machine; the heartbeat carries it to Nia (Nia 2026-11-19 or later), whose Agents page lists every machine's agents, unprotected first, with the command to run. A report decides nothing.

**Upgrade from 0.3.0**

`sudo sh update-linux.sh v0.4.0`, then `sudo nia-edge agents` to send the first report.

**Not yet**
- Governed is not confined: the agent's user keeps its files and network, and root can remove the hooks. Hermes and OpenClaw are confined by their installers.
- Codex's model calls through nia-edge (Claude Code: `-model`). Governing on macOS.
- Installers for OpenCode and Gemini CLI.

**Verify what you download**

```
sha256sum -c --ignore-missing SHA256SUMS
```

The builds are reproducible: `scripts/release.sh v0.4.0` on this tag, with Go 1.27.4, gives the same checksums.
