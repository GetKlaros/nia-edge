Fix release of nia-edge, the client of Nia. It is a pre-release.

**Fixed**
- **`pay` no longer fails on every payment.** 0.10.0 served the payment tool without Nia's payment plan: each call Nia allowed stopped with a panic before anything was sent, and the agent saw its MCP session end. Nothing was paid. The tool now asks Nia for the plan, and a machine whose payment tool misses a part refuses with a message, without spending the release.
- **A reused reference is reported as paid already.** The vault keeps one payment per reference; a retry it refuses for that reason now says so instead of "refused".

**Upgrade from 0.10.0**

`sudo sh update-linux.sh v0.10.1`, then `sudo -iu hermes hermes gateway restart`.
