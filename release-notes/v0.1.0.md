First release of nia-edge, the client of Nia. A pre-release: it has been tested against a Nia server, including the Linux installer in a machine with systemd and nftables, but not yet with a production agent.

**What it does**
- Enrolls the machine with a one-time token and keeps its key in a private file.
- Relays the agent's model and MCP calls to the Nia server, which decides every call.
- Runs the egress proxy: every outbound connection is decided by the machine's role; internal addresses are refused.
- `nia-edge doctor` proves, from the agent's user, that nia-edge is its only way out.
- `install/linux.sh` sets all of it up on Linux (systemd, nftables).

**Not yet**
- Decisions made on the machine: the server still sees and decides every call.
- A macOS installer. The macOS binaries are not signed or notarised.
- Local MCP servers.

**Verify what you download**

```
sha256sum -c --ignore-missing SHA256SUMS
```

The builds are reproducible: `scripts/release.sh v0.1.0` on this tag, with Go 1.27.4, gives the same checksums.
