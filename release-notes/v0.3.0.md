Third release of nia-edge, the client of Nia. It is a pre-release. It adds a second agent, OpenClaw, and a way to find the agents of a machine; every part below was run against Nia's end-to-end tests with a real OpenClaw.

**New**
- **Find the agents of a machine.** `sudo nia-edge agents` (or `-json`) lists the agents installed under every account (Hermes, OpenClaw, Codex, OpenCode, Claude Code): whether one runs, its MCP servers, whether its model is nia-edge, whether its user is the one nia-edge closes, the groups that go around it, and what to do next. It reads files and `/proc`, follows no link, prints no secret and decides nothing.
- **OpenClaw behind nia-edge.** `install/openclaw-linux.sh --from <user>` (or `--fresh`) moves OpenClaw to a user of its own, through OpenClaw's own CLI: the model is nia-edge and the agent keeps no provider key; every tool runs in a rootless Podman sandbox without network or host directory, `exec` never runs on the host, no tool of the model changes OpenClaw's configuration, Tool Search is off so that every call reaches Nia under its own name; the runtime and its MCP servers go through nia-edge's egress proxy. nia-edge's servers appear as `mcp__host__<action>` and `mcp__<name>__<tool>`, as with Hermes: the same roles apply.
- `install/mcp-linux.sh add` points an OpenClaw server at the container nia-edge runs for it.

**Upgrade from 0.2.0**

`sudo sh update-linux.sh v0.3.0`. From 0.1.0, run this release's installer once first (see the notes of 0.2.0).

**Not yet**
- Taking over OpenClaw's model provider: `NIA_PROVIDER_URL` and its key are required. Credentials OpenClaw keeps outside its configuration stay readable by the agent.
- Installers for Codex, OpenCode and Claude Code (they are found, not moved).
- A macOS installer. The macOS binaries are not signed or notarised.

**Verify what you download**

```
sha256sum -c --ignore-missing SHA256SUMS
```

The builds are reproducible: `scripts/release.sh v0.3.0` on this tag, with Go 1.27.4, gives the same checksums.
